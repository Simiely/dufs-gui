# 打包、产物校验与供应链

本页是 `build-guide` 的唯一权威：**怎么产出产物、怎么验证它没被换过**。
环境要求（Python 版本、路径限制）与逐项排错见 [使用指南](使用指南.md)，本页不重复。

## 一、三种产物形态

| 形态 | 怎么得到 | 启动开销 | 适用 |
|---|---|---|---|
| **onefile** | `build.bat` 默认 | 每次解压到 `%TEMP%\_MEI*`，1–3 秒 | 内网自用、单文件交付 |
| **onedir** | `set DUFS_GUI_MODE=onedir` 后打包 | 直接运行，快 | 分发（杀软误报低得多），可再套安装器 |
| **外壳 + payload 缓存** | 仓库外的 `_exp/build_release.py` | 首次解压约 1 秒，之后复用 | **本仓库无法复现**，仅用于发布包 |

> 第三种形态的脚本不在版本库里（`_exp/` 被 `.gitignore` 排除），因此
> 「双击 exe 即外壳形态、首次启动解压 payload」只对发布包成立。
> 从源码构建得到的永远是前两种之一。

## 二、构建可复现

- PyInstaller 固定在 [`requirements.txt`](../requirements.txt) 的 **6.22.3**
  （本机验证：CPython 3.14.6 / Tk 8.6）。CI 与本地安装同一精确版本；
  未锁传递依赖哈希，因为它是构建工具而非运行时依赖。
- 每次打包生成 `dist\BUILD-INFO.txt`：记录实际 Python、PyInstaller、Tk、dufs、
  皮肤版本与 Git 状态，回答"这个产物由哪套环境构建"。

## 三、产物校验

- 同时生成 `dist\SHA256SUMS`（sha256sum 格式）：exe + 关键构建输入
  （`bin\dufs.exe`、`assets\`、`licenses\`、`requirements.txt`、spec、两份校验和清单）。
  除 exe 外的条目是**打进包内的输入**，用于审计来源，不单独分发。
- 校验 exe：

  ```powershell
  Get-FileHash dist\DufsGui-v<版本>.exe -Algorithm SHA256
  ```

- 校验全部输入（在仓库根目录）：

  ```bash
  sha256sum -c dist/SHA256SUMS
  ```

## 四、测试与 CI

```bat
python -m unittest discover -s tests   :: 数量以实际输出为准；jsdom 皮肤 E2E 缺依赖时自动跳过
```

Windows CI 见 [.github/workflows/windows-ci.yml](../.github/workflows/windows-ci.yml)：

- **unittest** job：矩阵覆盖 Python 3.9 / 3.12，只跑标准库单测；
- **build-check** job：Python 3.14，安装锁定依赖 → 打包 onefile → `--selftest` →
  断言产物非空 → 生成并校验 `BUILD-INFO.txt` / `SHA256SUMS`。

runner 没有交互桌面，因此 build-check 不启动 GUI；CI 不负责发布
（无 tag 触发、无上传步骤）。

## 五、供应链校验

- dufs 版本固定在校验和清单 [`tools/dufs_checksums.json`](../tools/dufs_checksums.json)
  中（当前 `v0.47.0`），下载脚本不自动追 latest。
- 每个资产、**每一条下载来源**都有独立 SHA256；下载后逐个比对。哈希不符会立即
  失败并停止，**不会静默切换到下一个镜像**。只有网络失败才允许换源，且逐条打印原因。
- 内置皮肤的 `index.html` / `index.js` / `favicon.ico` 与官方逐字节一致，
  `index.css` 是"官方原始文件 + 本地覆盖层"；清单记录的是官方原始文件的哈希，
  见 [`tools/skin_checksums.json`](../tools/skin_checksums.json)。
- 清单中的哈希来自 GitHub Releases API 的官方 `digest`（sha256）字段。若某个来源
  留空，脚本会按 **TOFU（首次信任）** 记录哈希并写回清单：该策略只能发现
  "下载后被替换"，**无法发现首次下载即被投毒，不等价于上游签名**。
  升级版本时请先更新清单，不要让脚本跳过校验。
