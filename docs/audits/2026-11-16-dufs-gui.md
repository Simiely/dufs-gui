# 2026-11-16 文档审计

依据 `knowledge-base` 的单项目规范 **2.1.1** / repo-kit **2.5.1**。审计方式：只读比对 +
在一次性副本里做 dry-run，确认「迁移后可达全绿」后才动本仓库文件。

## 一、迁移范围

| 项 | 内容 |
|---|---|
| 机器层 | `tools/repo-kit/{check_repo,generate}.py`、`tools/update-repo-kit.ps1`、`schema/{taxonomy,sources,frontmatter.schema,kit.lock}.json`、`.github/workflows/repo-check.yml` |
| 契约 | 9 个文件补 frontmatter（使用指南、2 篇报告、6 篇坑页） |
| 索引 | 新增本目录的 `docs/index.md`、`docs/_template.md` |
| 生成 | `AGENTS.md` 改为由 `schema/agents.template.md` 生成；新增 `llms.txt`、`docs/_generated/*` |
| 真源 | `sources.json` 只配 `co_change`（`core/__init__.py` → README / AGENTS / 使用指南） |

`sources.json` **不用**标识符抽取模式：本仓文档 inline code 密集，抽取会把
`last_reviewed`、`review_days`、`wait_ready`、`element_create` 之类全判成 `TRUTH_DRIFT`（dry-run 实测 4 条）。

## 二、人审发现并修正的 8 处

机器层只保结构，下面 8 条全靠人读，逐条记录处理结果。

| # | 位置 | 原表述 | 问题 | 处理 |
|---|---|---|---|---|
| 1 | README 快速开始 / 首次启动预期 | 双击 exe 即「单文件外壳」，首次启动解压到 payload 缓存 | `build.bat` 只产普通 onefile；外壳由未入库的 `_exp/build_release.py` 产出 | 明确区分两种形态，并标注「无法从本仓库复现」 |
| 2 | README 常见问题 | onefile 每次解压到 `%TEMP%\_MEI*` | 与上条互斥 | 同一次改写里统一口径 |
| 3 | AGENTS 关键坑 6 | 勾选框用 `element_create` 替换 indicator | 已换 `ThemedCheckbutton`，`_install_check_indicator` 无调用点（死代码） | 改写为现行实现，并注明自绘图片需长期持有引用 |
| 4 | 坑页（assets 缺 index.html） | 「三件套全部自研」「皮肤默认关闭」 | 现状是官方 assets + CSS 覆盖，且默认开启 | 结论改为官方 assets + `fetch_skin.py` 同步；默认策略改为开启 + 失败自动降级 |
| 5 | 坑页（弹窗被裁切） | 「按 `winfo_reqheight` 实测」 | 现状是 `max(560, min(780, 屏高-120))` + 滚动兜底；`withdraw` 下 reqheight 返回 1 | 改写为按屏幕钳制，并写明 reqheight 不可用的原因 |
| 6 | 使用指南 共享网卡 | 「超过 7 行内部滚动」 | 代码 `BIND_MAX_ROWS = 20` | 改为 ≤20 行一次显示、超出滚动 |
| 7 | 使用指南 深色界面 | 「卡片/面板 10px」 | `RADIUS["card"] = 12` | 改为 12px，并注明 `core/theme.py` 是真源 |
| 8 | AGENTS 常用命令 | `dist\DufsGui-v1.6.13.exe` | `APP_VERSION` 已是 1.6.15 | 文档里不再写死版本，统一用 `v<版本>` 占位；只保留 README「版本」一节的当前值 |

另修：使用指南双 H1（`# 使用指南` 与 `# Dufs GUI` 并存）。
