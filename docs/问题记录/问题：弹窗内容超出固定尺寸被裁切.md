# 问题：弹窗写死尺寸，新增控件后内容被裁切

**TL;DR**：固定 `620x560` 撑不下新增的两行控件，底部被切掉。

- **问题**：高级设置弹窗底部（dufs 程序一行）看不见
- **根因**：`win.geometry("620x560")` 写死；新增「网页皮肤目录」及其说明后行数超出
- **解决**：**取消写死尺寸，按内容实测**——建完所有控件后读
  `outer.winfo_reqheight()`，加上下留白再套 `geometry`，并钳制到屏幕可用区。
  这样以后新增任何行都不会被切。另包一层 Canvas + 滚动条，屏幕矮时改为滚动而非截断
- **细节**：滚轮事件**只绑 Canvas 不够**，指针停在输入框/下拉框上时滚不动，
  必须递归绑到每个子控件
- **预防**：任何会增删内容的窗口，都不要写死高度
